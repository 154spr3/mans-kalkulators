Mans kalkulators 

Projekta apraksts

Šis projekts ir vienkāršs kalkulators, ko izveidoju datorikas stundas ietvaros. Kalkulators ļauj veikt matemātiskas darbības ar diviem skaitļiem.

Izmantotās tehnoloģijas

HTML — mājaslapas struktūrai.

CSS — dizainam un krāsām.

JavaScript — aprēķinu veikšanai.

Projekta mērķis
Projekta mērķis ir apgūt HTML, CSS un JavaScript pamatus, kā arī iemācīties publicēt projektu GitHub Pages.





1. Ko es izdarīju 
Izveidoju kalkulatoru, izmantojot HTML, CSS un JavaScript.
Izveidoju vienkāršu un saprotamu dizainu.
Pievienoju četras matemātiskās darbības: saskaitīšanu, atņemšanu, reizināšanu un dalīšanu.
Pievienoju rezultāta parādīšanu ekrānā.
Publicēju projektu GitHub Pages.

3. Ko es darīšu 
Pārbaudīšu, vai visas kalkulatora funkcijas darbojas pareizi.
Uzlabošu kalkulatora izskatu un dizainu.
Pievienošu projektam aprakstu un sakārtošu failus.
4. Kas ir procesā 
Projekta dokumentācijas jeb README.md sakārtošana.
Kalkulatora pārbaude un iespējamo uzlabojumu plānošana.
